twenty mac tools in one app

Turn on the tools you need; each asks for access only then.

Download PowerToys or read the source code. Requires macOS 15 or later on Apple silicon.

The modules

  • Windows and input: Zones, Window Switcher, Keys, Scroll & Mouse, Pin & Crop
  • System: Awake, System Toggles, Displays & Audio, Cleaner
  • Tools: Clipboard, Color Picker, Text Extractor, Batch Rename, File Locksmith, Finder Extras
  • Developer: Ports & Processes, Hosts & Env, Launch Agents, Defaults Browser, Screen Ruler

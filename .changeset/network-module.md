New Network module, off until you turn it on. Throttle the whole Mac with presets such as 3G, Edge or lossy Wi‑Fi, or your own speeds, delay and packet loss, for all traffic, DNS lookups only, chosen hosts or ports, stopping on a timer or when the app quits. Switch DNS servers, flush the DNS cache, add per-domain resolvers, turn a proxy on and off, see connection and Wi‑Fi details, run Apple's speed test, watch each app's network use, and show upload and download speed as its own menu bar item. Changes go through PowerToys' helper, which you allow once in System Settings. A throttle, and a proxy pointing at this Mac, end when PowerToys quits; DNS and other proxy settings stay.

Awake's root helper is now that same PowerToys helper, shared by both modules. If you had Keep awake with the lid closed on, it's off after updating and Awake says why: turn it on again and allow PowerToys once more under Login Items & Extensions in System Settings. The old helper is removed from there.
